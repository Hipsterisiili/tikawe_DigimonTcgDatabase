# tikawe_DigimonTcgDatabase
A database for storing information about Digimon cards and thair classifications.

The application accesses a database containing cards from Digimon Card Game. The cards as database entities have a couple attributes such as rarity, level and color. 

Users can also store their a virtual collection of cards in the database. User might also play a mock up draft with the cards in a collection where the draft outputs a CSV of the drafted cards so that the user can copypaste the card list to a different application and play with the drafted deck. 

Users can browse the collections  of other users, but only edit their own collection.

Admin level users can edit the entire database.
