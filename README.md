# tikawe_DigimonTcgDatabase
A database for storing information about Digimon cards and their classifications.

The application accesses a database containing cards from Digimon Card Game. The cards as database entities have a couple attributes such as rarity, level and color.

Users can also store and browse their virtual collection of cards in the database. Their collection can be added to and cards can be removed from the collection.

User might be able to have the application output their collection as a CSV file which they can copy/paste to a different application such as digimoncarddev.com.

The application contains a user page, which displays statistics of the user. Other users' collections can be viewed, but not edited.

Users can comment other users' collections. The comments are the secondary data entity of the application. 

Users can browse the collections of other users, but only edit their own collection.

Admin level users can edit the entire database.
